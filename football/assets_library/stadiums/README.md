# Stadiums

- Formato: `SVG` modular.
- Tamaño: paneles escalables para cenital y perspectiva.
- Variantes: `default`, `academy`, `broadcast`, `premium`.
- Anclas: centro de escena o módulos específicos.
- Punto de rotación: centro de cada módulo.
- Z-index recomendado: `40` a `140`.
- Colores heredables por Theme: cubierta, gradas, vallas, anillos, branding y luces.

Uso previsto:
- Carcasas de estadio, gradas, vallado y publicidad como piezas sustituibles.

# Academy

- Formato: `SVG`, `JSON` y presets de override por tema.
- Tamaño: independiente de resolución.
- Variantes: `default`, `light`, `dark`.
- Anclas: no aplica a sprites físicos; sí a overlays o insignias de marca.
- Punto de rotación: no aplica por defecto.
- Z-index recomendado: `900+` para overlays/branding.
- Colores heredables por Theme: paleta institucional, resaltes, fondos, bordes y tipografía.

Uso previsto:
- Overrides visuales del modo academia sin duplicar sprites base.

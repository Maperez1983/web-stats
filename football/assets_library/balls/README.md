# Balls

- Formato: `SVG`.
- Tamaño: lienzo base recomendado `128x128`.
- Variantes: `default`, `broadcast`, `premium`, `mini`.
- Anclas: `center-center`.
- Punto de rotación: centro exacto del balón.
- Z-index recomendado: `420` a `460`.
- Colores heredables por Theme: paneles, sombra, contorno, highlight.

Uso previsto:
- Balones de partido y entrenamiento con posible diferenciación por tema.

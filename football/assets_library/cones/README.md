# Cones

- Formato: `SVG`.
- Tamaño: lienzo base recomendado `128x128`.
- Variantes: `default`, `yellow`, `orange`, `blue`, `premium`.
- Anclas: `center-bottom`.
- Punto de rotación: base central.
- Z-index recomendado: `220` a `280`.
- Colores heredables por Theme: cuerpo del cono, borde, sombra, brillo.

Uso previsto:
- Conos y discos de marcaje sin depender de polígonos primitivos.

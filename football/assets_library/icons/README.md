# Icons

- Formato: `SVG`.
- Tamaño: base recomendada `64x64` o `128x128`.
- Variantes: `default`, `outline`, `filled`, `premium`.
- Anclas: `center-center`.
- Punto de rotación: centro exacto.
- Z-index recomendado: `700+` en overlays y paneles.
- Colores heredables por Theme: icon fill, stroke, glow, muted state.

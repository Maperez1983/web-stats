# Grass

- Formato: `SVG` con patrones repetibles.
- Tamaño: tile recomendado `256x256`.
- Variantes: `default`, `natural`, `broadcast`, `premium`.
- Anclas: no aplica.
- Punto de rotación: centro del patrón.
- Z-index recomendado: `0` a `20`.
- Colores heredables por Theme: césped claro, césped oscuro, highlights, sombreado.

Uso previsto:
- Césped definitivo del motor visual, separado de las texturas generales.

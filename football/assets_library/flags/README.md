# Flags

- Formato: `SVG`.
- Tamaño: lienzo base recomendado `128x256`.
- Variantes: `default`, `club`, `premium`.
- Anclas: `bottom-center`.
- Punto de rotación: base del poste.
- Z-index recomendado: `200` a `260`.
- Colores heredables por Theme: tela, poste, sombra, borde.

Uso previsto:
- Banderines de córner y banderas auxiliares del árbitro.

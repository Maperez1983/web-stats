# Textures

- Formato: `SVG` vectorial o patrones declarativos.
- Tamaño: repetible por tile; recomendado `128x128` o `256x256`.
- Variantes: `default`, `broadcast`, `premium`, `subtle`.
- Anclas: no aplica.
- Punto de rotación: centro del tile.
- Z-index recomendado: `0` a `40`.
- Colores heredables por Theme: base, highlights, ruido, sombreado.

Uso previsto:
- Texturas base y overlays ligeros del terreno o paneles visuales.

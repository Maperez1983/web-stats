# Coaches

- Formato: `SVG`.
- Tamaño: lienzo base recomendado `512x512`.
- Variantes: `default`, `academy`, `premium`.
- Anclas: `center-bottom`.
- Punto de rotación: centro corporal.
- Z-index recomendado: `280` a `360`.
- Colores heredables por Theme: ropa, silueta, borde, sombra, acentos.

Uso previsto:
- Entrenadores y miembros del staff en modo tarea/presentación.

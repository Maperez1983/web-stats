# Players

- Formato: `SVG` preferente, con posibilidad futura de `PNG/WebP` de apoyo.
- Tamaño: lienzo base recomendado `512x512` o múltiplos exactos.
- Variantes: `default`, `academy`, `broadcast`, `premium`, `outline`.
- Anclas: `center-bottom` para pies sobre el césped.
- Punto de rotación: centro del cuerpo, ligeramente por encima del eje de los pies.
- Z-index recomendado: `300` a `399`.
- Colores heredables por Theme: equipación primaria, secundaria, borde, dorsal, sombra, highlight.

Uso previsto:
- Familias para tokens estilizados, fotográficos y premium.
- El asset final debe poder sustituirse sin tocar la lógica del motor visual.

# Referees

- Formato: `SVG`.
- Tamaño: lienzo base recomendado `512x512`.
- Variantes: `default`, `yellow`, `black`, `premium`.
- Anclas: `center-bottom`.
- Punto de rotación: centro corporal.
- Z-index recomendado: `300` a `380`.
- Colores heredables por Theme: equipación arbitral, silueta, sombra, dorsal/insignia.

Uso previsto:
- Árbitros principales y asistentes como entidades visuales independientes.

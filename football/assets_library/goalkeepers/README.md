# Goalkeepers

- Formato: `SVG` preferente.
- Tamaño: lienzo base recomendado `512x512`.
- Variantes: `default`, `academy`, `broadcast`, `premium`.
- Anclas: `center-bottom`.
- Punto de rotación: centro corporal.
- Z-index recomendado: `320` a `420`.
- Colores heredables por Theme: equipación, guantes, borde, dorsal, sombra y glow.

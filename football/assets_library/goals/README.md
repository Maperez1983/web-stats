# Goals

- Formato: `SVG`.
- Tamaño: lienzo base recomendado `512x256`.
- Variantes: `default`, `broadcast`, `premium`, `training`.
- Anclas: `center-bottom`.
- Punto de rotación: eje medio de la portería.
- Z-index recomendado: `120` a `180`.
- Colores heredables por Theme: postes, red, sombra, contorno, reflejos.

Uso previsto:
- Porterías completas o miniporterías con geometría coherente y reemplazable.

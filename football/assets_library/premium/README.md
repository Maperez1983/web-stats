# Premium

- Formato: `SVG` y presets de composición premium.
- Tamaño: independiente de resolución, apto para exportación HD/4K.
- Variantes: `default`, `dark`, `light`.
- Anclas: dependientes del sprite al que se apliquen.
- Punto de rotación: heredado del sprite base.
- Z-index recomendado: `850+` para overlays y `300+` para assets temáticos.
- Colores heredables por Theme: paleta premium, gradientes, sombras, brillos y paneles.

Uso previsto:
- Sustituir placeholders por assets premium reales sin tocar la lógica de composición.

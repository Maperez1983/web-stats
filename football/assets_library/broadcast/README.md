# Broadcast

- Formato: `SVG` y overrides de theme orientados a TV/presentación.
- Tamaño: independiente de resolución.
- Variantes: `default`, `tv`, `clean`.
- Anclas: no aplica salvo overlays gráficos.
- Punto de rotación: no aplica por defecto.
- Z-index recomendado: `850+`.
- Colores heredables por Theme: líneas de emisión, rótulos, glow, contrastes y paneles.

Uso previsto:
- Overrides para una presentación tipo retransmisión.
